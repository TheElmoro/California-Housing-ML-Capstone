# California Housing ML Capstone

This repository contains the end-to-end Machine Learning pipeline for the California Housing dataset, developed as part of my Capstone project.

## Project Overview
This project demonstrates a full machine learning lifecycle including data preprocessing, regression analysis, classification, and unsupervised clustering. The codebase is designed for portability and can be executed across different environments with minimal configuration.

## Key Features
- **Regression:** Optimized Random Forest model for price prediction.
- **Classification:** Binary classification of house price tiers without data leakage.
- **Clustering:** K-Means clustering and PCA analysis for demographic profiling.
- **Interactive Dashboard:** Built-in widgets for real-time price estimation.

## How to Run
1. Clone this repository.
2. Ensure `scikit-learn`, `pandas`, `numpy`, and `ipywidgets` are installed.
3. Open `Capstone_ML_Project_Notebook.ipynb` in Google Colab or Jupyter.
